section: Bug fixes
- [user] Only a Goal's Owner can now set its Kind, delivery date, cadence and So What, add Contributors, add or edit Metrics, or Activate it. Until now anyone signed in, a Delegate included, could do these to any Goal by posting to its routes directly. They now get 403 and the Goal is left as it was. A command naming a Goal, Metric or other record that doesn't exist now gets the Not found page (404) instead of a server error (500) (#191).
