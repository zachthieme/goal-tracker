section: Breaking changes
- [api] **Spreadsheet import format**: a Dimension value can no longer contain a semicolon, since the import separates values with one; there is no escape for it. Before, such a value could be created in the app, but a download writing it could not be imported again. A download of Goals carrying one is now refused, naming the Dimension and the value; rename the value on the Dimensions page to a name without a semicolon, then download again (#101).

section: Bug fixes
- [user] A CSV saved by Excel as "CSV UTF-8" now imports: the byte-order mark Excel writes at the start of the file is ignored, where before the first column was reported as unknown (#101).
- [user] A Dimension value containing a semicolon is now refused, saying the import format uses it to separate values, wherever a value is added or renamed: on the Dimensions page, from a Goal's "add a value" input, from the Goal table's edit mode and by an import. A value already named with one still shows, filters and groups, and an Admin can rename it to a name without one. The Goal table's Download CSV refuses, naming the value, rather than writing a file that can't be imported again (#101).
