section: Breaking changes
- [ops] **Database schema / migrations**: migration `0040_several_narrative_notes` runs on startup and is one-way. It rebuilds `narrative_texts` without its `(report_definition_id, section)` primary key, adding an `id` column that keeps notes in the order they were entered. Each draft's existing note in a section becomes that section's first note. A build from before it can't read the upgraded table, so back the database up before upgrading (#187).

section: New features
- [user] On a Report's draft page, you can write as many of your own notes as you like into each narrative section (Insights, Accomplishments, Misses). Each note has its own box, and "Add another" adds an empty box to that section, keeping everything you've typed or ticked. Blank notes are ignored. The preview, the published Report and the Markdown export show each note as its own paragraph, in the order you entered them, before the Highlights you picked. Reports published before this change still show their notes (#187).
