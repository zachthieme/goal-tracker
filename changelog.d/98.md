section: Bug fixes
- [user] Dimensions and Fields share one set of names: defining a Dimension named like an existing Field, whatever its case or spacing, is now refused saying the Field has it, as the reverse already was, so the spreadsheet import can't confuse the two. Names that already collide are left as they are (#98).
- [user] Renaming a Dimension value to match another value in its list, whatever its case or spacing, is refused with a message saying to merge the two instead; changing only the case or spacing of a value's own name still renames it (#98).
- [user] On the Goal page, a one-value Dimension's select offers "None", and choosing it removes the Goal's value there with one "cleared" entry in its history; clearing a required Dimension leaves the Goal Incomplete. A retired value the Goal carries stays selected, so saving the select doesn't drop it (#98).
- [user] Setting or clearing a Goal's Dimension value or Field writes the change and its history entry together, so a change can no longer land without its history (#98).
- [user] A Retired Dimension's or Field's card no longer shows the Required mark or the control to change it; restoring it brings both back with the setting it had (#98).
