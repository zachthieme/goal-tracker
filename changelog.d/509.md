section: Code quality
- [internal] `make lint` now also runs `noctx`, `bodyclose`, `errorlint` and `contextcheck`, so a request or query made without a context, an HTTP response body left open, an error compared with `==`, and a dropped context fail the lint. Migrations take the caller's context (`db.Migrate(ctx, db)`), the app's listeners listen under it, and the web tests close every response body and make their requests under the test's context (#509).
