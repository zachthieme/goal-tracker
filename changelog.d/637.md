- [internal] The test harness names its failure injection: `FailWrites(Insert|Update|Delete, table)` makes those writes to a table fail with `injected failure`, and `FailReads(table)` makes reads of it fail with `no such table`, in place of the triggers, renames and drops tests wrote by hand (#637).
- [internal] The test harness builds its migrated template database once per test binary, in about 0.11s under the race detector, rather than caching it under `$TMPDIR/goal-tracker-testdb` for every binary and later runs, so the cache's naming and clean-up code and its tests are gone, `db.Migrations` with them, and `go test -trimpath` runs the harness's tests (#637).
