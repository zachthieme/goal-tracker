section: Improvements
- [user] Milestones read the same way on the Goal page, a Report's exception blocks and its Markdown export: a mark, then the date, then the name. The mark is Done, Removed, Red (overdue), Yellow (its date has slipped) or New (added since the Report's baseline, or on the Goal page by the latest Check-in), the first that applies; a Milestone on track has no mark. The date is the current one, then the date it last slipped from struck through, and how many times it slipped when that is more than once, e.g. `2026-11-20 ~~2026-11-03~~ (3)`; older slipped dates are no longer listed. The Goal page's Milestones table now reads Status, Date, Milestone. The marks don't change a Goal's Health. Reports published before this change show their Milestones the new way too (#189).
