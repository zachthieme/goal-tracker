section: New features
- [ops] `GOAL_TRACKER_START_AT`, test-only: set to an RFC 3339 instant, the app's clock (the domain's "now" and the weekly-email scheduler) starts there and then ticks normally. Startup logs a WARN with the instant when it's set, and stops with an error naming the variable when it doesn't parse. Unset, the app reads the wall clock as before (#230).

section: Testing
- [internal] The e2e suite runs against a frozen org: both templates are seeded relative to 5 October 2026 (`default` with `-end 2026-10-05`, `due` with `-end 2026-10-01`), each test's app starts its clock at 2026-10-05T18:05:00Z, and the specs read "now" from the app (`app.now()`, `appToday()`, `$now` in `seedLookup`) instead of the machine's clock, so a Goal's seeded Health no longer changes from day to day (#230).
