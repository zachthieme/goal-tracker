section: Security
- [ops] Issuing a set-password link is logged at INFO with who issued it (the Admin's account ID and email, or `issuer=command-line` for `goal-tracker password-link`), the person it's for and when it expires; the link and its token are never logged. Each **Sync now** is logged at INFO naming the Admin who asked (#495).
- [internal] The domain checks the Admin itself behind a set-password link (`IssuePasswordLink` takes the actor; the command line uses `IssueOperatorPasswordLink`) and behind Sync now (`SyncDirectoryAsAdmin`, `directory.Sync.RunForAdmin`), refusing anyone else with `ErrNotAuthorized` before creating or reading anything (#495).
