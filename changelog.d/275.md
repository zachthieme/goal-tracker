- [user] Goals and Risks now share one **Scope** select, the first control in each page's filter bar: **Everyone**, **Mine**, **My org** (when you have anyone under you), then each other person's org under **Other orgs**. It replaces the Goals list's **Mine only** checkbox and **Any org** select, and the Risks page's Everyone / Mine / My org buttons, so each page has scope in one place. Mine and an org no longer combine: the page is scoped to one at a time, an org taking over from Mine on both pages, where the Goals list used to show only the Goals in both. Mine's address is now `?org=mine`; old `?mine=1` links still work. The Risks count line names the scope too ("3 Goals need attention in My org. Worst first.") (#275).
