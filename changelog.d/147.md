section: Breaking changes
- [ops] **Database schema / migrations**: migration `0039_report_rules` runs on startup and is one-way. It converts each saved Report Definition to the new model, then drops the `report_definition_roots` and `report_definition_filters` tables and the `depth` and `owner_filter_id` columns of `report_definitions`. A definition with only filters becomes Report rules: an "Owner is" rule for its Owner filter and one "is any of" rule per filtered Dimension. A definition with roots becomes a hand-picked list, frozen to the Goals it selected at upgrade: its roots walked down accepted links to its Depth, then kept by its Owner and Dimension filters. One whose Goals all fail its filters is left with an empty list and drafts no Goals. It adds `report_definitions.mode` and the `report_rules`, `report_rule_values` and `report_definition_goals` tables. A build from before it can't read the upgraded database, so back the database up before upgrading (#147).

section: Improvements
- [user] A Report no longer follows Contributes to links: the New report form has no Depth, its Root Goals save as the Goals picked (only those passing its Owner and Dimension filters as you save), and its filters alone save as Report rules. A Goal that was Done or Cancelled before the Report's baseline drops out of it, however it was selected, so finished work is reported once (ADR 0007) (#147).

section: Architecture
- [internal] A Report Definition is a `Mode` of rules or picked: `Rules` (Dimension, Owner, Lifecycle, Health and Top-level rules with "is", "is any of" and "is not", ANDed, their values ORed) with `Include` (Also include) and `Exclude` (Leave out), or a `Picked` list. `SelectGoals` takes the `since` predicate `DraftReport` reads changes with, keeps a Goal that changed Lifecycle since the baseline under a Lifecycle rule, and drops Goals finished before it. `SaveReportDefinition` refuses each input with an `InputError` naming it (`name`, `mode`, `rules`, `rules[i]`, `include`, `exclude`, `picked`, `fields`). Merging a Dimension value repoints every rule listing it. `SelectDescendants` is gone (#147).
