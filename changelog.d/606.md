section: Architecture
- [internal] A Report's draft page is built from one view, `reportDraftView`, through one builder, for the page, a refused Report Delegate add and a plain Add another. It reads through its own page loader, `Service.ReportDraftPage`, which ADR 0010 records as the third. The page drops from 39 queries to 33 of its own, besides the session's and the sidebar's: it no longer reads the open Action Items twice, re-reads the Goals' Check-ins, Milestones and Date Slips for counts it doesn't show, or reads the Report Definition again to judge each open Action Item. `querycount_reportdraft_test.go` pins the page and both Add another outcomes, and fails any query run twice beyond those it lists (#606).
