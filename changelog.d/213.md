section: Bug fixes
- [ops] A request the client abandons, such as a checklist post on `/goals/new` or `/goals/{id}/define` that htmx replaces with a newer one, is no longer logged as `level=ERROR msg="server error" ... context canceled`. It's logged at DEBUG as `msg="request abandoned"` with the method and path, so it's hidden at the default level. Any other server error, including a `context canceled` on a request the client is still waiting for, is still logged at ERROR with its cause (#213).
