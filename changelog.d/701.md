- [user] Six commands now answer a refusal the way every other command does. Creating a Goal, or sending the New goal or define form, when refused for who is asking shows the refusal page at 403 instead of a 500 (`TestCreatingAGoalRefusedForWhoIsAskingIsTheRefusalPage`, `TestAGoalFormRefusedForWhoIsAskingIsTheRefusalPage`). A Delegate change refused for making a cycle comes back on the Goal page with the Delegates form open, or as the refusal page at 409, instead of a 500 (`TestADelegateChangeMakingACycleAnswersInPlaceOrWith409`). A Top-level change refused for what was asked shows the refusal page at 422 instead of a 500 (`TestARefusedTopLevelChangeIsTheRefusalPage`). The Goal's Owner pressing Suggest a parent gets the refusal page at 403 instead of the form again (`TestTheOwnerSuggestingAParentGetsTheRefusalPage`). An import that fails for a reason the app doesn't give shows the logged 500 error page instead of the Import page saying "The import failed." (`TestAFailedImportIsTheLoggedErrorPageOverHTTP`). Remove Admin of an id that is no one's Account still shows the Not found page, on purpose, since there is no such Account (`TestAdminCantRemoveTheirOwnAdminRole`) (#701).
