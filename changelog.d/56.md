section: Improvements
- [user] Four actions that can be put right afterwards no longer stop you with a browser dialog: rejecting a link request (on Home and the Pending links page), rejecting a Handoff, removing a link from the Goal page, and retiring a Dimension value. Each happens as soon as you press it. A rejected request or Handoff can be asked again, a removed link can be requested again, and a Retired value can be restored. Marking an Owner departed or a person returned, cancelling a Goal, retiring a whole Dimension or a Field, and merging a value still ask first (#56).
