section: Improvements
- [user] An open Action Item about a Goal, listed in the weekly reminder, now links to the publication it was raised on, at its Action Items (`/reports/{report}/publications/{publication}#action-items`), as its raise and reassign emails already did, where it used to link to the Goal's page (#609).

section: Architecture
- [internal] One `EmailComposer` in `internal/domain/emailcomposer.go` builds every outbound email — the Action Item email, the comment alert, the Nudge, the weekly reminder and the Parent digest — and one `AppLinks`, built from the Service's base URL, builds every app link in them. The domain commands and notify both call it (`Service.EmailComposer`); notify only gathers facts and queues, and `notify.New` takes the Service alone, so `cmd/goal-tracker` passes the base URL only to `domain.WithBaseURL`. `internal/web/emaillinks_test.go` checks every `AppLinks` link reaches a registered GET route (#609).
