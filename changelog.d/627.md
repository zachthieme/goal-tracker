section: Architecture
- [internal] One domain command, `SetGoalDimensionValues`, sets a Goal's values in a Dimension from the values chosen and an optional typed name, joining those the Goal carries or becoming exactly what it carries, and states each rule once: one value per Goal, who may add to a Fixed list, Retired values, and matching a typed name. Its check-only mode is Goal definition's value check. `AssignGoalValue`, `AssignGoalValueByName` and `SetGoalValues` are thin adapters over it; the Goal table, Goal definition and the Goal page's Dimension form call it directly, and an edit judges who may set the Goal's values once (#627).
