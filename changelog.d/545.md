section: Improvements
- [ops] A weekly-emails run that keeps failing is still tried at every poll, but no longer logs an `ERROR` a minute: `msg="weekly emails failed"` is logged at the first failure and then after waits of 1, 2, 4… minutes, at most an hour, with `failures` counting the polls failed so far. Each line now names the `job` and the `slot` it was for, and a run that recovers logs `msg="weekly emails recovered"` at `INFO` once (#545).
- [ops] An email send error quoting an address with a quoted local part, such as `"john doe"@example.com`, is now logged with all of that address redacted as `[address]`, not just what follows the closing quote (#545).

section: Testing
- [internal] The race between a Reassign and an Accept of the same Goal now checks the loser too: a losing Accept gets `ErrNotFound`, and a losing Reassign `ErrValidation` (#545).
