section: Testing
- [internal] The test harness's `SetManager` and `SetTimezone` record a person's Manager and Timezone through `SyncDirectory`, over a new in-memory Directory adapter (`testsupport.Directory`, `h.SyncDirectory`), instead of writing `accounts` directly, so a test builds its Org through the sync's own rules (ADR 0008). Either one now fails the test on a Timezone the sync refuses or on any Manager cycle in the database, and the tests that store a cycle or a self-reference on purpose do it with `h.SyncDirectory` and assert the cycle it returns. A zero manager now clears the person's Manager (#654).
