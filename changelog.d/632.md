section: Testing
- [internal] `make test` runs in under a minute rather than about 3½ (49s against 3m22s on 48 cores). modernc's SQLite allocator lock is per process, so `make test` builds `internal/web`'s test binary once and runs it as five processes, one per range of test names in `WEB_TEST_RANGES`, alongside a `go test` of every other package. Before running any test it fails naming each web test that matches no range, or more than one, so every test still runs exactly once. `CLAUDE.md`'s gate timings and the `vetinari/Dockerfile` comment give the new times (#632).
