section: Improvements
- [internal] The sidebar is read only when the layout draws the page frame, once per request, through a memoised reader the signed-in routes put in the request context: a POST that only redirects (such as a Nudge), an htmx fragment (such as a refused Check-in) and a download (such as the Goals download) no longer run its 11 queries. `querycount_noframe_test.go` pins all three, and that a framed page still runs every one. A request whose handler fails and whose sidebar read fails too now logs the handler's ERROR before the sidebar's `sidebar read failed` WARN (#628).
