section: Bug fixes
- [ops] **Metrics and access log**: a request for a path no route serves is now counted, timed and logged with `route="unmatched"` and its 404 (or 405), not under `GET /`, so `goal_tracker_http_request_duration_seconds{route="GET /"}` times only the index page itself (#536).
- [ops] **Email outbox**: a failed send's error is logged with anything shaped like an email address in it replaced by `[address]`, so a mail server's error that quotes the recipient doesn't bring their address into the retry and give-up lines (#536).
