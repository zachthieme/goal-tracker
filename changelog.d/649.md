section: Bug fixes
- [user] Defining a Goal on the New goal or Finish defining page no longer adds a value to a Fixed Dimension's list, even for an Admin: a value typed for a Fixed Dimension is refused there with "<Dimension> is a Fixed list, so a value can't be added to it here", and the Dimensions page, the Goal page and the Goal table still add one for an Admin. The Ready to activate checklist now counts a Proposed Goal's saved Kind, and its saved value in a Field, when the post leaves them out, as Activate Goal does (#688).

section: Architecture
- [internal] The Ready to activate checklist is judged by one domain judge, `domain.JudgeDefinition`, from the same `DefinedGoalInput` that `CreateDefinedGoal` and `DefineGoal` take plus the Proposed Goal's `SavedDefinition`; `DefinitionDraft` and the web layer's second translation of the form are gone. The six goal-form handlers build their view through one builder, `buildGoalForm` (#649).
