section: Infrastructure
- [ops] The `Dockerfile` pins its base images by digest beside their tags (`golang:1.27.3-bookworm@sha256:…`, `debian:bookworm-slim@sha256:…`), so a rebuild uses the same images until the digests are moved on purpose. Its apt packages, Chromium included, stay unpinned (#510).
- [internal] CI pins `actions/checkout` (v4.4.0) and `actions/setup-go` (v5.6.0) by commit SHA, and no longer installs golangci-lint with `curl | sh`: `make lint` builds the Makefile's v2.15.0 with `go run`, which the Go checksum database verifies (#510).
- [internal] `.github/dependabot.yml` asks for weekly updates to the Go modules, the app's `Dockerfile` and the CI Actions. It ignores `golang` version updates, since Go moves by hand with `go.mod` and `vetinari/Dockerfile`, but still refreshes the pinned digests. Dependabot acts only on the default branch on GitHub, so it does nothing until `main` is pushed (#418, #510).
- [internal] templ moves to v0.3.1070 and `modernc.org/sqlite` to v1.61.0, with the generated `*_templ.go` regenerated. The new templ renders a space between a component call and text on the next line, so the templates drop that text's leading space, write it straight after the call, or render it with a component (the nav label), and the pages read as before: "Olive Owner's", not "Olive Owner 's" (#510).
