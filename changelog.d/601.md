section: Bug fixes
- [user] A form posted to a Goal that doesn't exist (Add or Remove Delegate, Add Milestone, Request link, Hand off, Reassign, a Field or a Dimension value, or the Goal table's Save naming such a Goal) now gets the Not found page, as opening the Goal does, instead of a 500 or a refusal saying the Goal does not exist (#601).

section: Code quality
- [internal] Every Goal command and Goal-page probe opens its Goal one way, `openGoalCommand`: it loads the Goal (a missing one is `ErrNotFound`, any other read failure returned as it is, never as a refusal), applies the command's rule, then refuses unparsed input, and returns the Goal so the command doesn't read it again. The set-delivery rule is `setDeliveryRefusal` in `goalrules.go`, so `MarkGoalDated` and `MarkGoalOngoing` read their Goal once, and an Active Goal marked Dated with no date is refused for its Lifecycle first (#601).
